# Void theme for Galaxy S23 Ultra

A dark, void-themed set to go with the void elf wallpaper: icon pack, Always On Display animation,
notification sound, ringtone and a colour palette for Theme Park.

| File | What it is |
| --- | --- |
| `void-icons.apk` | Icon pack app (76 apps). Install it, then import it in Good Lock › Theme Park › Icon › Create new › Icon pack. |
| `void-icons-png.zip` | The same icons as 512 px PNGs, named by app, for Theme Park › Change icons › Gallery. |
| `void-portal-aod.gif` | Looping void portal for Lock screen › Always On Display › Clock style › Image. |
| `void-whisper.ogg` | Notification sound. |
| `void-call.ogg` | Ringtone (19 s loop). |
| `preview-icons.png` | All icons on one sheet. |

## Rebuild

Everything is generated by `src/build.sh` (icons drawn as SVG and rendered in Chromium; the AOD
animation and sounds are synthesised in Python; the APK is built with aapt2/d8/apksigner, no Gradle).
Edit `src/icons.py` to add apps or change glyphs, then run `src/make_appfilter.py` and `src/build.sh`;
the header of `build.sh` lists what it needs.

Glyphs: [Lucide](https://lucide.dev) (ISC) and [Simple Icons](https://simpleicons.org) (CC0; brand marks
belong to their owners).
