# zetsuu123.github.io

- [YGO Card Scanner](https://zetsuu123.github.io/ygo-scanner/): scan Yu-Gi-Oh! cards and look them up on Cardmarket ([source](ygo-scanner/)).
- [Runeblade 3D](https://zetsuu123.github.io/sword/): interactive 3D model of a skull-hilted runeblade, built procedurally with three.js from a reference photo; [runeblade.glb](sword/runeblade.glb) is the exported model ([source](sword/)).
